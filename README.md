# 📺 寶寶電視 Baby TV

一個給小朋友使用的白名單 YouTube 播放器。

家長預先放好影片，小朋友只能睇清單內的影片。搜尋只會搜這個片單，不會去 YouTube 搜，也沒有演算法推薦、留言或「相關影片」。影片播完會自動播同一個台的下一條，循環播放。

適合覺得 YouTube Kids 過濾不夠嚴格、想自己決定小朋友睇乜的家長。

## 檔案

成個網站就係一個 `index.html`：畫面、程式、預設片單都在入面。改介面或加片，改呢個檔就得。

`README.md` 只係說明書，改佢唔會改變網站。

## 功能

- **白名單片單** —— 每條片要有自己的 YouTube 影片 ID。這不係 YouTube 頻道白名單：批准一個頻道，唔代表呢個頻道之後的新片會自動出現。
- **電視台** —— 「台」名一樣的片會歸做一組，例如 `📚 教育台`、`🔴 Numberblocks 1`。台名可以加 emoji。
- **YouTube 式畫面** —— 頂欄、搜尋、左邊選單、橫向片架、播片頁。左上角標誌顯示 YouTube。
- **深色模式** —— 頂欄月亮或太陽可以即時切換。家長設定可以揀跟裝置、淺色或深色，選擇記在這部機。
- **片單內搜尋** —— 搜片名同電視台。打字會出建議。搜尋框有麥高峰，可以講片名；要用 https 網址先用到。鎖住的台唔會出現在結果。
- **自動連播** —— 只播同一個台的下一條。片完前幾秒，右下角會出「下一集」倒數，可以取消。
- **繼續睇、已睇紀錄、已儲存** —— 記在這部機。睇到一半再入返，會由停低嘅位置繼續。
- **時長同進度** —— 這部機播過之後，縮圖先會顯示時長同紅色進度。讀時長唔會計入每日限時。
- **訂閱、讚、踩、儲存** —— 只記在這部機，唔會真係去 YouTube 訂閱或讚。分享會複製這條片在本 App 的連結。
- **每日限時** —— 平日（一至五）同週末（六、日）分開設，單位係分鐘，填 0 代表沒有限制。時間到會鎖定，家長密碼可以加時 15 分鐘。
- **瞓覺時段鎖** —— 例如晚上 8 點到朝頭 7 點。密碼可以暫時解鎖 15 分鐘。
- **鎖台** —— 指定的台要家長密碼先開到。
- **觀看統計** —— 過去 7 日，同最多睇的片。
- **同步碼** —— 匯出一段碼，在另一部裝置匯入，片單同設定一齊搬過去。
- **跨平台** —— 同一條網址，iPhone / iPad / Android / Windows / Mac 都用到。

預設片單有「🎨 節目台」「📚 教育台」、Numberblocks 第 1 至第 5 季的官方完整單集（第 1、2 季各 15 集，第 3 至 5 季各 30 集），以及「🧡 Blippi Playtime」。Blippi 呢一台係官方頻道 [Blippi Playtime](https://www.youtube.com/@BlippiPlaytime) 影片分頁的快照，共 1173 條，由新到舊。頻道之後的新片唔會自動加入，Shorts 亦未收錄。

## 全家片單（Supabase）

`index.html` 入面的 `CLOUD.url` 同 `CLOUD.anon` 有值時，打開頁面會先顯示呢部機上次的片單，再讀雲端。讀到就更新畫面。讀唔到就繼續用副本。

小朋友唔使登入都睇到。改片單、限時、瞓覺、鎖台、按鍵音，要喺家長設定登入雲端帳戶，先會寫入全家。其他裝置下次打開先會跟到。4 位數字密碼仍然只係擋住呢部機打開設定。

觀看進度、讚、儲存、訂閱、深淺色、今日計時留喺呢部機，唔會上傳。

已經用緊的裝置，如果本機片單同雲端唔同，第一次會問：用全家片單，定係將呢部機的片單變成全家片單。未揀之前唔會覆蓋。

同步碼係離線備份。未登入雲端就匯入，只改呢部機。

資料表喺 `supabase/schema.sql`。公開網址同公開鑰匙可以放喺網頁。服務用的秘密鑰匙只留喺 Supabase，唔好寫入網頁，亦唔好推上 GitHub。`CLOUD` 已填寶寶電視專案的公開網址同公開鑰匙。

## 自己架設（免費）

1. 註冊 [GitHub](https://github.com) 帳號
2. 建一個新 repository（例如 `baby-tv`），**Visibility 必須選 Public**
3. 將 `index.html` 上傳到呢個 repository
4. **Settings → Pages**，Source 選「Deploy from a branch」，Branch 選 `main`，按 Save
5. 等 1–2 分鐘，網址會係：
   `https://你的用戶名.github.io/baby-tv/`

> 不能直接雙擊 HTML 檔案在本機開（`file://` 會出現 Error 153）。YouTube 嵌入式播放器要求從正式網址載入，所以要放上 GitHub Pages 或其他網頁空間。

## 小朋友點用

1. 在首頁的片架擦一擦，或者擦左邊一個台
2. 擦一條片的縮圖
3. 之後可以唔使再擦 —— 同一個台會自動連播、循環

> iOS 第一次可能要擦一下播放器先會開始（Apple 對自動播放的限制）。之後的自動連播不受影響。

## 家長設定

擦右上角頭像，或者左邊「家長設定」，輸入密碼。**預設係 `1234`，第一次用請即刻改。**

設定頁可以：

- **編輯片單**：一開收成每個台一行，例如「Blippi Playtime · 1173 條」。撳開先可以搜或者刪某一集；片多的台要打片名先列出。「＋ 加一條片」仍然可以加。ID 一格貼成條 YouTube 連結都得，會自動抽 ID。
- **分台**：「台」打同一個名，就會歸做同一個台。
- **每日限時**：平日、週末分開。
- **瞓覺時段鎖**、**鎖台**、**觀看統計**
- **匯出 / 匯入同步碼**
- **外觀**：跟裝置、淺色或深色
- **按鍵音效**、**更改密碼**（留空代表唔改）

### 點更新片單

| 方式 | 適合 | 效果 |
|---|---|---|
| App 內設定頁儲存 | 日常加減影片 | 只影響呢部裝置 |
| 改 `index.html` 裡的 `DEFAULT_VIDEOS` | 想新裝置用同一套預設 | 未在設定頁儲存過的裝置，會用新預設 |
| 在 `index.html` 加新的片集包 | 已經儲存過設定的裝置都要有新片 | 下次開頁會補上欠缺的片，唔會清走自己加的片。呢個包補過一次之後，再刪走的片唔會自動番返來 |

裝置一旦在設定頁按過「儲存」，就以部裝置自己的片單為準，不會成個被檔案裡的預設片單覆蓋。

## 常見問題

**影片有廣告嗎？**
用 YouTube 官方嵌入式播放器。有沒有廣告，見瀏覽器登入的 YouTube 帳號。登入 YouTube Premium 就沒有廣告。呢個 App 沒有擋廣告。

**可以離線睇嗎？**
不可以。影片經 YouTube 串流，要有網絡。

**更新了片單，畫面沒變？**
瀏覽器快取。Windows 按 `Ctrl + F5`。手機把頁面或 App 完全關掉再開。

**忘記家長密碼？**
清除呢部裝置瀏覽器入面呢個網站的資料。密碼會番返 `1234`，呢部裝置的片單同設定也會番返預設。

**小朋友會唔會按 Home 走去玩第二樣？**
App 鎖唔住呢個。iOS 用「引導使用模式」（設定 → 輔助使用 → 引導使用，按三下側邊鍵鎖定）。Android 用「螢幕固定」。Windows 可以按 F11 全螢幕。

**某條片播唔到？**
可能上傳者不准嵌入、片已刪除，或者係私人影片。換一條就得。
